📋 PROBLEMAS QUE FORAM CORRIGIDOS

PROBLEMA 1: "unrecognized arguments: --keep-unicode-filenames"
──────────────────────────────────────────────────────────────
ANTES:
  icloudpd -u "$EMAIL" \
    -d "$DIR" \
    --keep-unicode-filenames \    ← Não existe!
    --download-everything          ← Não existe!

DEPOIS:
  icloudpd -u "$EMAIL" \
    -d "$DIR"
  
  (Simples, sem argumentos que não existem)

PROBLEMA 2: "IndexError: list index out of range"
──────────────────────────────────────────────────
ANTES:
  duplicate_detector.py tentava processar lista vazia
  Python: IndexError (crash)

DEPOIS:
  Verifica se lista está vazia
  Se vazio: mostra mensagem e sai normalmente
  Se tem arquivos: processa normalmente

PROBLEMA 3: "[: 0\n0: integer expression expected"
──────────────────────────────────────────────────
ANTES:
  Variável tinha quebra de linha: "0\n0"
  Comparação [ "0\n0" -lt 50 ] = erro

DEPOIS:
  Usa: tr -d ' ' para limpar variáveis
  Comparação funciona: [ "0" -lt 50 ] = OK
