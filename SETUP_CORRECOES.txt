CAUSA: 3 BUGS NO SCRIPT ORIGINAL

BUG 1: Loop infinito na seleção
────────────────────────────────
  Problema: select_volume_correct() chama show_main_menu()
            que chama select_volume_correct() novamente
  
  Resultado: Depois da seleção, volta a perguntar
  
  Solução: Remover a função que chama recursivamente
           Retornar o volume diretamente

BUG 2: Teste de validação fraco
────────────────────────────────
  Problema: Valida com [ ! -d "$disk_path" ]
            Mas o disco pode estar montado com outro caminho
  
  Resultado: Mesmo disco selecionado, depois não encontra
  
  Solução: Testar com `test -d` e verificar permissões
           com teste de escrita real

BUG 3: Múltiplas chamadas a list_volumes()
────────────────────────────────────────────
  Problema: Função chama a si mesma múltiplas vezes
            Mostra "Detectando volumes..." repetidamente
  
  Resultado: Confunde e repete seleção
  
  Solução: Chamar list_volumes() UMA VEZ antes da seleção
           Não chamar de novo durante validação

PRINCIPAIS MUDANÇAS NO ARQUIVO FIXED

1️⃣  REMOÇÃO DE RECURSÃO

Antes:
  show_main_menu() {
    select_volume_correct
    show_main_menu  ← BUG! Infinito
  }

Depois:
  select_volume() {
    list_volumes  ← Uma vez
    read choice
    return volume ← Retorna e pronto
  }

───────────────────────────────────────────────────────────────

2️⃣  VALIDAÇÃO MAIS ROBUSTA

Antes:
  if [ ! -d "$disk_path" ]; then
    error "Diretório não encontrado"
  fi

Depois:
  # Teste 1: Existe?
  if [ ! -d "$disk_path" ]; then
    error "Diretório não encontrado"
    return 1
  fi
  success "Diretório existe"
  
  # Teste 2: Tem permissão?
  if [ ! -w "$disk_path" ]; then
    error "Sem permissão"
    return 1
  fi
  success "Tem permissão"
  
  # Teste 3: Tem espaço?
  if [ $available_gb -lt 50 ]; then
    warning "Espaço baixo"
  fi

───────────────────────────────────────────────────────────────

3️⃣  SELEÇÃO SEM LOOPS

Antes:
  - Pede seleção
  - Repete até contar até o número certo
  - Pode entrar em loop infinito

Depois:
  - Pede seleção UMA VEZ
  - Valida número (1 a max)
  - Retorna o volume imediatamente
  - Sem retry

───────────────────────────────────────────────────────────────

4️⃣  MELHOR DETECÇÃO DE VOLUMES

Antes:
  for volume in $(ls -d "$DOWNLOADS_DIR"/*/ 2>/dev/null | sort -r)
  
  (Procura em downloads? Deveria procurar em /Volumes)

Depois:
  for volume in /Volumes/*; do
    if [ ! -L "$volume" ] 2>/dev/null; then
      if [ "$volume" != "/Volumes/Macintosh HD" ]; then
        # Encontrou volume válido
      fi
    fi
  done

───────────────────────────────────────────────────────────────

5️⃣  TESTES SEM FALHAR

Antes:
  set -euo pipefail
  
  (Falha em qualquer erro, mesmo em testes)

Depois:
  set -uo pipefail
  
  (Remove -e para testes não interromperem o script)
  + Testes explícitos com `||` para controlar erro
