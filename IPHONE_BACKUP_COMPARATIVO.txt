💡 FLUXO RECOMENDADO (COMPLETO)

PASSO 1: Backup de fotos (nossos scripts)
─────────────────────────────────────────
$ ./backup_icloud_macos.sh

Resultado:
  /Volumes/SSD1TB/icloud_backups/downloads/
  ├── Todas as fotos/vídeos do iCloud
  ├── Sem duplicatas
  └── Organizadas por data

PASSO 2: Backup completo do iPhone (Finder)
────────────────────────────────────────────
1. Conectar iPhone no Mac via USB
2. Abrir Finder
3. Selecionar iPhone na barra lateral
4. Clicar "Fazer Backup Agora"

Resultado:
  ~/Library/Application Support/MobileSync/Backup/
  └─ Backup COMPLETO do iPhone (local)

PASSO 3: OPCIONALMENTE iCloud
──────────────────────────────
1. iPhone Settings → [Seu Nome] → iCloud
2. Ativar "iCloud Backup"
3. Conectar WiFi + carregar iPhone
4. Tudo sincroniza automaticamente

RESULTADO FINAL:
  ✓ Fotos do iCloud em disco externo (nossas)
  ✓ Backup completo do iPhone no Mac (Finder)
  ✓ Backup automático na nuvem (iCloud)
  ✓ Totalmente protegido

📖 COMO FAZER BACKUP DO IPHONE NO FINDER

PASSO 1: Conectar iPhone
  1. Conectar iPhone no Mac via USB
  2. Aguardar carregar

PASSO 2: Abrir Finder
  1. Finder → Sidebar (esquerda)
  2. Procurar iPhone
  3. Clicar no iPhone

PASSO 3: Fazer Backup
  1. Opção 1: "Fazer Backup Agora" (rápido)
  2. Opção 2: "Criptografar backup" (mais seguro)

PASSO 4: Aguardar
  - Pode levar 5-30 minutos
  - Barra de progresso mostra status
  - Não desconectar durante o backup

RESULTADO:
  ✓ Backup automático em: ~/Library/...
  ✓ Restaurável a qualquer hora
  ✓ Criptografado
  ✓ Completo
