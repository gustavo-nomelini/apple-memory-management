ETAPA 1: PREPARAR AMBIENTE (2 minutos)

───────────────────────────────────────────────────────────────

1️⃣  COMANDO: Limpar e atualizar Python/pip

$ pip3 install --upgrade pip

ESPERADO: "Successfully installed" ou já está atualizado

───────────────────────────────────────────────────────────────

2️⃣  COMANDO: Instalar Pillow

$ pip3 install --force-reinstall Pillow

ESPERADO: "Successfully installed Pillow"

───────────────────────────────────────────────────────────────

3️⃣  COMANDO: Instalar icloudpd

$ pip3 install --force-reinstall icloudpd

ESPERADO: "Successfully installed icloudpd"

───────────────────────────────────────────────────────────────

4️⃣  COMANDO: Adicionar PATH (copie TUDO, é uma linha só)

$ echo 'export PATH="$PATH:$HOME/.local/bin"' >> ~/.zshrc

ESPERADO: Sem mensagem = OK

───────────────────────────────────────────────────────────────

5️⃣  COMANDO: Recarregar configuração

$ source ~/.zshrc

ESPERADO: Sem mensagem = OK

───────────────────────────────────────────────────────────────

6️⃣  COMANDO: Testar Pillow

$ python3 -c "from PIL import Image; print('✓ Pillow OK')"

ESPERADO: ✓ Pillow OK

───────────────────────────────────────────────────────────────

7️⃣  COMANDO: Testar icloudpd

$ icloudpd --version

ESPERADO: icloudpd, version X.X.X

───────────────────────────────────────────────────────────────

Se algo falhar acima, PARE e me mostre o erro exato.
Se tudo OK, continue para Etapa 2.

═══════════════════════════════════════════════════════════════

ETAPA 2: SELECIONAR VOLUME (2 minutos)

───────────────────────────────────────────────────────────────

8️⃣  COMANDO: Dar permissão ao seletor de volume

$ chmod +x select_volume.sh

ESPERADO: Sem mensagem = OK

───────────────────────────────────────────────────────────────

9️⃣  COMANDO: Executar seletor de volume

$ ./select_volume.sh

ESPERADO: Mostra lista de volumes
          Você digita: 2 (para SSD1TB)
          Mostra: "✓ Pronto para fazer backup!"

═══════════════════════════════════════════════════════════════

ETAPA 3: FAZER BACKUP (1-4 horas, depende do tamanho)

───────────────────────────────────────────────────────────────

🔟  COMANDO: Dar permissão ao script de backup

$ chmod +x backup_icloud_macos.sh

ESPERADO: Sem mensagem = OK

───────────────────────────────────────────────────────────────

1️⃣1️⃣  COMANDO: Iniciar backup

$ ./backup_icloud_macos.sh

ESPERADO: 
  - Pede email iCloud
  - Pede senha (pode usar "Senha Específica do App")
  - Pede código 2FA (se ativado)
  - Começa a baixar fotos/vídeos
  - Mostra progresso

DURANTE O BACKUP:
  • Deixe rodando
  • Pode fechar Terminal se quiser (vai continuar)
  • Ou abrir outro Terminal para monitorar

───────────────────────────────────────────────────────────────

MONITORAR PROGRESSO (em outro Terminal):

$ chmod +x backup_monitor.sh
$ ./backup_monitor.sh --summary

ESPERADO: Mostra arquivo baixados, tamanho, velocidade

═══════════════════════════════════════════════════════════════

ETAPA 4: APÓS BACKUP COMPLETAR (5 minutos)

───────────────────────────────────────────────────────────────

1️⃣2️⃣  COMANDO: Analisar duplicatas

$ chmod +x duplicate_detector.py
$ python3 duplicate_detector.py /Volumes/SSD1TB/icloud_backups/downloads/$(date +%Y-%m-%d)

ESPERADO:
  - Mostra duplicatas encontradas
  - Gera relatórios em TXT e JSON
  - Mostra espaço que pode ser economizado

───────────────────────────────────────────────────────────────

1️⃣3️⃣  COMANDO: Fazer segundo backup (CRÍTICO!)

$ rsync -av /Volumes/SSD1TB/icloud_backups/ /Volumes/OutroDisco/backup/

IMPORTANTE:
  - /Volumes/SSD1TB é seu disco primário
  - /Volumes/OutroDisco deve ser outro disco (USB, thunderbolt, etc)
  - Isto vai levar 15-60 minutos dependendo do tamanho

ESPERADO: Mostra arquivos sendo copiados

───────────────────────────────────────────────────────────────

1️⃣4️⃣  COMANDO: Verificar integridade (certifique-se que copiou certo)

$ diff -r /Volumes/SSD1TB/icloud_backups/downloads /Volumes/OutroDisco/backup/downloads

ESPERADO: Sem mensagem = Cópias são idênticas (perfeito!)

═══════════════════════════════════════════════════════════════

ETAPA 5: LIMPEZA E FINALIZAÇÃO (5 minutos)

───────────────────────────────────────────────────────────────

1️⃣5️⃣  COMANDO: Limpar duplicatas (SEGURO - 3 confirmações)

$ chmod +x safe_cleanup.sh
$ ./safe_cleanup.sh /Volumes/SSD1TB/icloud_backups/reports/duplicates_*.txt

IMPORTANTE: Isto vai pedir 3 confirmações
ESPERADO: Mostra arquivos movidos para quarentena (não deletados!)

───────────────────────────────────────────────────────────────

1️⃣6️⃣  COMANDO: Liberar espaço no iPhone/iCloud

Abrir em um navegador:
  https://iCloud.com

1. Fazer login
2. Fotos
3. Selecionar Todos (Cmd+A)
4. Delete
5. Esvaziar Lixo

IMPORTANTE: Só faça isso DEPOIS de ter 2 backups completos!

SOLUÇÃO: pip3 install icloudpd

SOLUÇÃO: pip3 install --force-reinstall Pillow

ERRO: "2FA required"
SOLUÇÃO: Usar "App-Specific Password" em appleid.apple.com
         (não sua senha normal)

🎁 BÔNUS: CRIAR ATALHOS NO TERMINAL

Depois que setup terminar com sucesso:

$ echo "alias icloud-backup='./backup_icloud_macos.sh'" >> ~/.zshrc
$ echo "alias icloud-analyze='python3 duplicate_detector.py'" >> ~/.zshrc
$ echo "alias icloud-clean='./safe_cleanup.sh'" >> ~/.zshrc
$ source ~/.zshrc

Depois você pode digitar:
  icloud-backup          (em vez de ./backup_icloud_macos.sh)
  icloud-analyze PATH    (em vez de python3 duplicate_detector.py PATH)
  icloud-clean FILE      (em vez de ./safe_cleanup.sh FILE)
