🎯 PASSO A PASSO

PASSO 1: Preparar o Mac e iPhone (2 minutos)
─────────────────────────────────────────────

1. Abra seu Mac
2. Conectar iPhone com cabo USB:
   ✓ USB-C (iPhone 15+)
   ✓ Lightning (iPhone 14 e anteriores)
   ✓ Adaptador USB-A se necessário

3. Aguarde o iPhone carregar um pouco (2-3 min)

───────────────────────────────────────────────────────────────

PASSO 2: Abrir o Finder
─────────────────────────

1. Clique no ícone do Finder (rosto sorridente) no Dock
   └─ Se não tiver no Dock: Cmd + Space → digita "Finder"

2. Vai abrir a janela do Finder

───────────────────────────────────────────────────────────────

PASSO 3: Encontrar o iPhone no Finder
──────────────────────────────────────

1. Procure no lado ESQUERDO da janela (Sidebar):
   
   ┌─────────────────────────────┐
   │ Finder                      │
   ├─────────────────────────────┤
   │ 📱 iPhone [Seu Nome]   ← aqui │
   │ Documents                   │
   │ Downloads                   │
   │ Desktop                     │
   └─────────────────────────────┘

2. Clique NO IPHONE para selecioná-lo

3. Aguarde 2-3 segundos para carregar

───────────────────────────────────────────────────────────────

PASSO 4: Opções de Backup
──────────────────────────

Quando o iPhone está selecionado, você vê duas opções:

   ┌──────────────────────────────────────────┐
   │ Fazer Backup Agora (Sem criptografia)   │
   │ Backup Criptografado (Recomendado)      │
   └──────────────────────────────────────────┘

ESCOLHA: "Backup Criptografado"
RAZÃO: Mais seguro, protege dados sensíveis

───────────────────────────────────────────────────────────────

PASSO 5: Executar o Backup
───────────────────────────

1. Clique em "Backup Criptografado"

2. Aguarde 5-30 minutos (depende do tamanho)

3. Barra de progresso mostra o status:
   ▓▓▓▓▓░░░░░ 50%

4. Quando terminar, mostra mensagem de sucesso

IMPORTANTE: Não desconecte o iPhone durante o backup!

───────────────────────────────────────────────────────────────

PASSO 6: Verificar o Backup
────────────────────────────

Quando o backup terminar:

1. Você verá no Finder:
   "Backup concludente em [hora]"

2. Informações do backup aparecem abaixo:
   • Data do último backup
   • Tamanho do backup
   • Espaço disponível

3. Tudo pronto! ✓

🔄 FAZER BACKUPS REGULARMENTE

OPÇÃO 1: Manual (Controle Total)
─────────────────────────────────
1. Conectar iPhone no Mac
2. Abrir Finder
3. Clicar "Fazer Backup Agora"
4. Pronto

Recomendação: Uma vez por semana

OPÇÃO 2: Automático (sem fazer nada)
──────────────────────────────────────
iPhone Settings → [Seu Nome] → iCloud → iCloud Backup:
  1. Ativar "iCloud Backup"
  2. Conectar WiFi + carregar iPhone à noite
  3. Automático em background

Recomendação: Ativar TAMBÉM para redundância

MELHOR: Fazer os dois!
  • Finder (local, rápido)
  • iCloud (automático, nuvem)

💾 ONDE O BACKUP É ARMAZENADO

Automaticamente em:
  ~/Library/Application Support/MobileSync/Backup/

Você NÃO precisa fazer nada, o macOS gerencia.

Se quiser ver:
  1. Finder → Go (menu superior)
  2. Go to Folder...
  3. Cole: ~/Library/Application Support/MobileSync/Backup/
  4. Enter

Mas não recomendo mexer lá.

🆘 PROBLEMAS COMUNS

PROBLEMA: "iPhone não aparece no Finder"
SOLUÇÃO:
  1. Desconectar e reconectar cabo
  2. Confiar no iPhone: "Confiar neste computador?"
  3. Reiniciar Finder (Cmd+Q, depois abrir de novo)
  4. Atualizar macOS e iOS

PROBLEMA: "Backup travou na metade"
SOLUÇÃO:
  1. Desconectar iPhone
  2. Fechar Finder
  3. Reconectar iPhone
  4. Tentar novamente

PROBLEMA: "Sem espaço no Mac"
SOLUÇÃO:
  1. Limpar cache do Mac
  2. Deletar arquivos grandes não usados
  3. Usar disco externo (abaixo)

═══════════════════════════════════════════════════════════════

💡 DICA: BACKUP EM DISCO EXTERNO

Se quiser backup do iPhone no SSD1TB (junto com fotos iCloud):

1. Fazer backup no Mac primeiro (acima)
2. Depois copiar:
   ~/Library/Application Support/MobileSync/Backup/
   Para seu SSD1TB

Comandos (Terminal):
  cp -r ~/Library/Application\ Support/MobileSync/Backup/ \
    /Volumes/SSD1TB/iPhone_Backup/

Resultado:
  /Volumes/SSD1TB/iPhone_Backup/
  ├── icloud_backups/      (nossos scripts)
  └── Backup do iPhone     (Finder)

Tudo em um disco!
