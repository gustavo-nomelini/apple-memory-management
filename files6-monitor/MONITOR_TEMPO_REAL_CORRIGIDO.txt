🐛 BUGS QUE FORAM CORRIGIDOS

ERRO 1: "MAGENTA: unbound variable"
────────────────────────────────────
CAUSA: Código tentava usar variável MAGENTA que não existia
       
ANTES:
  echo "${MAGENTA}..."  ← Variável nunca foi definida

DEPOIS:
  # Variável MAGENTA removida
  # Usar cores já definidas: CYAN, YELLOW, GREEN, etc

═════════════════════════════════════════════════════════════

ERRO 2: "Tamanho Total: 0.00 B" (com 825 arquivos!)
────────────────────────────────────────────────────
CAUSA: `du -sb` retorna resultado com newlines/espacos
       Variável `total_bytes` acumulava quebras de linha
       
ANTES:
  total_bytes=$(du -sb "$DOWNLOAD_DIR" | awk '{print $1}')
  # Resultado: "123456\n" (com quebra de linha!)

DEPOIS:
  total_bytes=$(du -sb "$DOWNLOAD_DIR" | awk '{print $1}' | tr -d ' ')
  if [ -z "$total_bytes" ]; then
      total_bytes=0
  fi
  # Resultado limpo: "123456"

═════════════════════════════════════════════════════════════

ERRO 3: "Velocidade média: 0 MB/s" (sempre)
────────────────────────────────────────────
CAUSA: Cálculo de velocidade não funcionava corretamente
       Usando bc que não estava disponível
       
ANTES:
  speed_mb=$(echo "scale=2; ($bytes / 1048576) / $seconds" | bc)
  # bc pode não existir, resulta em erro
  # Variável fica vazia, mostra "0"

DEPOIS:
  awk "BEGIN {printf \"%.2f MB/s\", ($bytes / 1048576) / $seconds}"
  # awk sempre disponível no macOS
  # Cálculo funcionando corretamente

═════════════════════════════════════════════════════════════

ERRO 4: Loop infinito travando
───────────────────────────────
CAUSA: Script tinha loop `while true` mas travava ou não atualizava
       
AGORA:
  # Loop contínuo correto
  while true; do
    # Atualizar dados
    file_count=...
    total_bytes=...
    
    # Mostrar tudo
    echo ...
    
    # Atualizar variáveis de tempo
    LAST_SIZE=$total_bytes
    LAST_TIME=$current_time
    
    # Aguardar 2 segundos
    sleep 2
  done

═════════════════════════════════════════════════════════════

ERRO 5: "Tamanho atual: 0.00 B" também
───────────────────────────────────────
CAUSA: Mesma causa do tamanho total
       Variável não era limpa corretamente
       
SOLUÇÃO: Usar `tr -d ' '` para remover espaços/newlines

✅ PRINCIPAIS MUDANÇAS

1. REMOVER variável MAGENTA
   - Usar apenas: RED, GREEN, YELLOW, BLUE, CYAN, NC
   - Sem variáveis undefined

2. LIMPAR variáveis com tr -d
   - total_bytes=$(... | tr -d ' ')
   - file_count=$(... | tr -d ' ')
   - Garante números limpos

3. USAR awk ao invés de bc
   - awk está sempre disponível
   - Cálculos funcionam corretamente
   - Sem erros de comando não encontrado

4. VALIDAR valores antes de usar
   if [ -z "$total_bytes" ]; then
       total_bytes=0
   fi
   - Evita erros com variáveis vazias

5. LOOP CONTÍNUO SIMPLES
   - while true
   - Atualizar dados
   - Dormir 2 segundos
   - Repetir
